# CosPlan · Cosplay 计划器

一个给 coser 自己用的出装管家。**不用注册、不用联网，（也没有跳转广告）你记的所有东西都只存在你自己的设备里。**

## 它帮你解决的都是出装路上的琐碎

- 出了好几个角色，哪条裙是哪个角色的、放在柜子哪一层，翻衣柜想不起来
- 妆娘毛娘摄影师约了一遍，价格、档期、定金全散在微信聊天记录里
- 拍完照说好两周返图，催片催到忘
- 一套出装到底花了多少钱，从来没算清过
- 租的假毛快到期了、快递该到了，全靠脑子记

这些它都记得住，而且会主动提醒你。

## 三分钟上手

**电脑**：双击打开那个 `cosplan-1.5.11.2.html` 文件就行，浏览器会自动打开。把这个文件存在一个你找得到的地方。

**手机**：安装 APK 包（安装时系统问"是否允许未知来源"，选允许）。打开就是 app。

**第一步**：打开后点「＋ 新出一个角色」，填作品名、角色名、时装名（默认"原皮"），项目就建好了。里面所有字段都是**能填就填、能省则省**——只填你想记的。
苹果手机建议用网址（也可以v我点米发行苹果版本）
周围没有用鸿蒙的，不知道那边状态如何
## 它能帮你记什么

| 出装阶段 | 它记什么 |
|---|---|
| 置装 | 每件装备（C服/道具/假毛/美瞳/鞋）买到哪一步了：还在购物车、已下单、在途、到了、试穿合不合适；借的、租的、快递单号、预期到货都记 |
| 约人 | 妆娘毛娘摄影师修图师的联系方式、平台 ID、价格、档期、定金付没付、避雷备注 |
| 拍摄 | 拍摄日期地点摄影师、出装清单打勾（自动生成，含应急包）、出装日现场大字模式 |
| 拍后 | 说好什么时候返图，逾期自动标红提醒你催；发布到哪个平台也记一笔 |
| 花钱 | 装备价格、定金尾款自动记账，设了预算快超会提醒；出完片一键生成复盘：这套花了多少、回血多少 |
| 记忆 | 履历墙把出过的套摆一墙；每件装备记"偏大/合身/偏小"，下次买直接翻记录 |
| 沟通 | 尺寸卡（头围等假毛数据）、集合信息卡，一键复制粘进微信就能发 |

另外还有：两件同类装备并排对比、租借到期提醒、每晚八点手机推送明天的安排（安卓版）。

## 你的数据安全吗

- **只存在你自己手里**：不联网、不上传、没有账号服务器，数据就在你打开它的那台设备的浏览器里。手机版同理，存在手机里。
-
- 备份文件里含联系人电话等信息，别发到公开的地方。
- **电脑和手机是两份独立数据**：想把电脑上的记带到手机，电脑上导出备份 → 把文件传到手机 → 手机上「导入（覆盖）」。

## 出新版本了怎么更新

- **电脑**：直接打开新版 html 文件。数据自动接上，不用做任何操作。
- **手机**：直接安装新 APK 覆盖旧的，数据保留。
- 旧版本文件留着别删——万一新版有问题，打开旧文件就回去了，数据还在。

## 手机安装时弹"未知来源"怎么办

第一次安装时系统会拦一下，选择「允许」即可（这是所有非应用商店安装的正常提示，只影响这一次）。
