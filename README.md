# cosplayplan
CosPlan 是一款为 Cosplayer 设计的本地化出 cos 管理工具。
从选角立项、装备采购与制作，到妆造预约、拍摄执行、返图交付和发布复盘，CosPlan 把一套 cos 的全过程集中管理。你可以记录 C 服、假发、美瞳、道具等装备的状态与花费，追踪借还、租赁、到货和低库存；为项目设置预算、截止日期与提醒；建立摄影师、妆娘、场地等联系人档案；并在出装当天打开现场模式，直接核对装包清单、地址和拍摄安排。
它尤其适合同时筹备多套角色、容易遗漏小物件或想复盘开销的 Cosplayer。所有数据默认保存在本机，不上传、不联网；支持 JSON 备份、图片库，以及导出 Word、Excel、CSV 格式的装包单。
一句话介绍：
CosPlan：把“这套 cos 还差什么、花了多少、哪天拍、该带什么”一次管清楚。
